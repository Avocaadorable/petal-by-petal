# Petal by Petal

Build a calm single-player florist game for Windows and macOS. The first milestone is one complete customer commission: distinctive conversation, preference-led flower arranging in a 3D vase, and gentle feedback/payment. Use the owner's soft watercolor art direction.

Verify a Godot project with `GODOT_BIN=/Applications/Godot.app/Contents/MacOS/Godot ./scripts/check.sh`.
