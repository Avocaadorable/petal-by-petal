# Design bible reference art used by the prototype

`shop-scene.png` is a crop from page 8 of the owner's provided `design-bible.pdf`, rendered locally from the PDF at 3× page scale. It is used as the prototype's shop-scene backdrop to keep the game grounded in the approved watercolor art direction. It is an owner-provided visual reference asset, not a capture from the gameplay reference.
`florist-character.png` and `logo.png` are crops from page 10 of the same owner-provided design bible. They are used directly as the character illustration and wordmark in the prototype.
