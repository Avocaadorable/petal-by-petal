# Heartbeat reference

The generic project workflow can use Orca automation on a 30-minute schedule with a precheck, deadline, map Issue, and a short per-tick work limit. A scheduled process survives a chat session and requires Orca to remain running.

## Owner setting — Q10

Background work and recurring tasks are disabled. Do not create an automation, schedule, or continue development after the current explicitly requested task. Wait for the owner's explicit instruction before beginning each new development task. The prior template's automation command is retained only as reference and is not authorization to run it.
