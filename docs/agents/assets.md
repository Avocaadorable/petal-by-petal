# Generated and sourced assets

## Budget and route

Owner Q7 sets both per-session and total spending caps to **$0**. Do not run paid Flora generations or any other paid asset service. Use assets supplied by the owner, procedural assets created in Godot, or free assets whose license allows the intended use. Start with one flower and validate the complete arranging workflow before expanding the asset library.

## Free-asset checks

Record source, author, license, and any attribution or share-alike requirements in `assets/PROVENANCE.md` before adding a third-party asset. Keep reference captures in ignored local `study/` only. Keep copyrighted reference game assets out of the public repository and shipped build.

## Future generation workflow

Flora remains connected but is not an allowed asset route under the current $0 cap. A future explicit change to the budget is required before a paid generation. If the budget changes, show the quoted price and obtain explicit approval for that spend before calling a paid generation. Inspect every generated mesh before importing it into Godot; record its model, input, and cost in provenance.
